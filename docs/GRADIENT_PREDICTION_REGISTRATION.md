## 定义（与 `scripts/first_answer_confidence.py` 及论文 Table `tab:keep` 相同）

- M1：以"九个独立采样中与第一答案相同的个数"为分数、第一答案是否正确为标签的 ROC 曲线下面积。数据：qwen4-max 的 A 与 A3。
- M2：reassuring loop（A2）中，当前答案正确时下一轮保留它的比例，除以当前答案不正确时的比例。

## 预测规则

阈值取已有设置中"批评有用"与"批评不需要"两个设置的中点：M1 = .60，M2 = 1.12。

- 若 qwen4-max 的 **M2 < 1.12**：预测 G-S2（selected(critique) − selected(reassuring) > 0）成立。
- 若 **M2 ≥ 1.12**：预测 G-S2 不成立。
- M1 作为辅助记录：M1 与 M2 落在阈值同侧（M1 < .60 且 M2 < 1.12，或 M1 ≥ .60 且 M2 ≥ 1.12）记为"一致"，否则记为"不一致"并照实报告。预测以 M2 为准，因为 M2 直接来自与 G-S2 对比的那个条件。

## 判定

- 预测"成立"且 G-S2 的 Holm 校正 p < .05、差为正：预测正确。
- 预测"不成立"且 G-S2 未达到上述标准：预测正确。
- 其余：预测错误。

## 已知弱点

- 阈值来自两个点，且这三个量是看过数据后选的。
- M2 与 G-S2 共用 reassuring loop 的数据，二者不独立：M2 高本身就意味着 reassuring loop 选得好。这个预测检验的是"M2 的阈值能否迁移到新模型"，不是独立证据。
- 无论结果如何，论文附录 M 都报告这次预测及其对错。
