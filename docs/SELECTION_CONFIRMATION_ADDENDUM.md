# 附加规格：新 800 题上的独立采样基线与"只看题目的批评"（qwen；v1，2026-11-17 22:20，先于这两个条件在新题上的任何运行）

> 本文件是 `SELECTION_CONFIRMATION_SPEC.md` v1.1 的附加部分。**时间顺序如实记录：** 原规格没有包括独立采样（A3），S1、S2、R1 已于 2026-11-17 读出（`CONTROLS_RESULTS.md`）。本文件在那之后写定，写定时 A3 与 C2Q 在新题上没有任何运行或数据。S1、S2、R1 的判定不因本文件改变，本文件的两个检验单独成组、单独校正。
> 名称：A3 独立采样（nine samples），C2Q 只看题目的批评（question-only critique），C2QY 为 C2Q 续跑到 critique loop 的 token 预算。

## 1. 要检验的两件事

- **T-A3**：critique loop 选对的题多于九次独立采样的多数答案。这与原 400 题上的预设主检验是同一个检验（三个模型上成立：+20.7、+23.1、+12.2），这里在新题上重做。
- **T-Q**：critique loop 选对的题多于花同样多 token 的"只看题目的批评"。原 400 题上为描述性结果（+22.3 [8.4, 36.8]），这里第一次作为预设检验。

## 2. 设计

- 模型 `qwen3.8-flash-payg`；题目为已抽定的 800 道新题（hle_401–hle_1200），不得更换或剔除。
- A3：与原运行相同（T=0 的首答沿用 A 的结果，其后九次 temperature 0.7 的独立采样），量的定义与论文相同（九次采样的多数答案）。
- C2Q → C2QY：与原 400 题上的做法完全相同，分两步。先按自然停止规则跑 C2Q；再从它的轨迹续跑到预算（`EQUAL_TOKEN_CONTROLS_SPEC.md` v4 的续跑模式，预算文件 `yoke_budget_qwen_confirm.json`，token 口径为 solver 加逐轮记录的 critic，上限 100 个反馈轮）。不改代码。
- 判分：冻结口径，输出到新文件 `experiments/hle400/t3/is_correct_t3_sidecar_confirm2.json`（三节：A3、C2Q、C2QY；C2QY 已有轮次的判分从 C2Q 原样抄入）。运行期间不查看对错。

## 3. 读出（脚本 `scripts/selection_confirmation_addendum_readout.py`，数据到齐后编写，只实现本节）

- **等 token 轨迹**（C2QY）：每题取到累计 token 第一次达到或超过该题预算的那一轮为止（含这一轮）；C2Q 自然停止时已超预算的题同样读到该轮。对齐判据：对齐后的总量在预算总量的 95%–120% 之间，且跑满 100 轮仍未到预算的题不超过 40 道。不成立则 T-Q 标为"token 未对齐，不作判定"。
- **两个检验**（Holm 校正，这一组的总 α = .05）：
  - T-A3：selected(C2) − selected(A3) > 0。
  - T-Q：selected(C2) − selected(C2QY，等 token 轨迹) > 0。
  - 题目级符号翻转置换检验（10,000 次），双侧，方向须与假设一致；题目级 bootstrap 95% 区间。
- **描述性报告**：reached 的不一致对（C2 对 A3；C2 对 C2QY，并按 R1 的方式给出 90% 区间与 ±33 的关系）；只计精确匹配下的两个检验；A3 的 token 与每题候选数；A3 对 reassuring、对 token-yoked 的 selected 之差；C2Q 自然停止时的 reached、selected；C2QY 全部轮次口径；按学科与题型的分层；新旧 1,200 题合并（探索性）。
