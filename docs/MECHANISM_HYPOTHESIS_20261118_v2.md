## 0. 一句话假设

> **循环是一个有记忆的采样器；记忆让票集中；集中是好是坏，取决于被重复的那个答案对不对。**
> **记忆的强度就是模型对答案的把握。** Critique 分不清对错，但它只推得动模型没把握的答案；没把握的答案里错的更多，所以推一推平均是赚的。赚多少，取决于模型在没把握时自己守住正确答案的水平。

- **对安慰剂**：critique 改变"票投给谁"。净值 ≈（把握低且首答错的题 × 修复率）−（把握低但首答对的题 × 额外丢失率）。
- **对 self-consistency**：critique loop 的票相关、会重复，独立采样的票摊开；优势主要在 conversion，不在 reach。
- **模型之间**：critique 这个算子在各模型上大致相同；差别在模型自身（第 8 节的三个量）。

## 5. 结果 4：模型差异在模型自身，不在 critic

800 题上四个条件的 selected：

| | reassuring | generic | token-yoked | critique | 极差 |
|---|---|---|---|---|---|
| deepseek | 256.2 | 248.5 | 261.5 | 254.2 | 13.0 |
| qwen | 168.5 | 183.2 | 181.5 | 205.3 | 36.8 |

- DeepSeek 对反馈类型几乎不敏感；Qwen 敏感。DeepSeek 的 critique 绝对值高于 Qwen 的 critique：不是 critique 在 DeepSeek 上失效，而是它的基线已经很高。
- **v2 注**：第一批 400 题上三个 loop 的极差折算到 800 题约为 deepseek 25、qwen 47，差距没有新题上大；同一条件重跑一次，400 题上 selected 会变动 3–4 题。"两个题集一致"只在方向上成立。

**Critique 这个算子在各模型上大致相同（逐轮转移，`mechanism_tables.py`）**：

| cell | 答对后保持：reassuring → critique | 答错后保持：reassuring → critique | 答错后改对：reassuring → critique |
|---|---|---|---|
| deepseek 400 | .92 → .74 | .56 → .26 | .062 → .112 |
| qwen 400 | .78 → .59 | .57 → .29 | .066 → .122 |
| MiniMax 400 | .84 → .62 | .60 → .37 | .058 → .092 |
| qwen 800 | .75 → .49 | .61 → .30 | .073 → .144 |
| deepseek 800 | .88 → .62 | .65 → .31 | .071 → .144 |

**停留优势**（票数 ≈ 进入次数 × 停留长度，停留长度 = 1/(1 − 保持概率)；正确答案相对错误答案，新 800 题）：

| | reassuring | critique | 进入正确答案的概率 |
|---|---|---|---|
| qwen | 1.6 倍 | 1.4 倍 | 约翻倍 |
| deepseek | 2.9 倍 | 1.8 倍 | 约翻倍 |

两个模型在 critique 下进入正确答案的机会都翻倍，正确答案的停留优势都被削弱。Qwen 的优势本来就小，损失一成多，净赚；DeepSeek 的优势大，损失近四成，抵消。

## 7.（新）记忆的强度 = 模型对答案的把握

把握在 loop 之外测得：九次独立采样中与首答相同的次数；分层在计算前定为 0–3、4–6、7–9（`confidence_strata.py`，新 800 题）。

**"loop 结束时多数答案仍是首答"的比例（首答对 / 首答错）：**

| | 把握低（0–3） | 把握中（4–6） | 把握高（7–9） |
|---|---|---|---|
| qwen 题数（对 / 错） | 81 / 394 | 40 / 100 | 25 / 118 |
| qwen reassuring | .46 / .42 | .88 / .86 | .96 / .98 |
| qwen critique | .45 / .27 | .78 / .67 | .92 / .87 |
| deepseek 题数（对 / 错） | 85 / 299 | 43 / 88 | 70 / 114 |
| deepseek reassuring | .69 / .48 | .95 / .80 | .99 / .97 |
| deepseek critique | .54 / .28 | .93 / .69 | .96 / .91 |

**selected：reassuring → critique**

| | qwen | deepseek |
|---|---|---|
| 把握低、首答错 | 39.9 → 64.4（+24.5） | 37.8 → 47.3（+9.5） |
| 把握低、首答对 | 58.1 → 52.9（−5.2） | 78.3 → 67.8（−10.5） |
| 把握中、首答错 | 3.0 → 12.0 | 9.0 → 9.0 |
| 把握中、首答对 | 37.0 → 34.0 | 42.0 → 40.5 |
| 把握高、首答错 | 0.0 → 7.0 | 1.0 → 3.5 |
| 把握高、首答对 | 24.0 → 23.0 | 69.0 → 67.5 |

**四类题**

| | 首答对 | 首答错 |
|---|---|---|
| 把握高 | critique 推不动，无得无失 | critique 基本救不回来 |
| 把握低 | 损失的来源 | 收益的来源 |

- Critique 推不推得动，主要看把握，不看对错：把握高时，对的保留 .92–.96，错的也保留 .87–.91。
- 这解释了简单题：首答把握高，critique 既改不坏也无可改好，偏移小。
- 净值 ≈（把握低且错的题数 × 修复率）−（把握低但对的题数 × 额外丢失率）。
- 一个做不成方法的检验：只在把握低时才用 critique 的策略，用现有数据离线计算并不优于全程 critique（qwen 181.3 对 193.3；deepseek 236.1 对 235.6），因为 qwen 在把握中、高的题上 critique 仍有净收益。

## 8.（新）AI 的"元认知"：三个可测量

"模型知不知道自己在犯错"是拟人的说法。这里把它定义为三个由行为测得的量，不对模型的内部状态作任何断言。

| 量 | 定义 | qwen（新 800） | deepseek（新 800） |
|---|---|---|---|
| **M1 监测**：把握能否区分对错 | 采样与首答的一致次数对首答正确性的区分度（AUROC；0.5 为完全不能区分） | 0.54 | 0.60 |
| | 把握高（7–9）的题里首答正确的比例 | 25/143 = 17% | 70/184 = 38% |
| **M2 控制**：没人质疑时是否守对弃错 | reassuring 下，答对后保持 / 答错后保持 | .75 / .61 | .88 / .65 |
| | reassuring 下，把握低的题里多数答案仍是首答：首答对 / 首答错 | .46 / .42 | .69 / .48 |
| **M3 显式自评**：critic 的输出是否随对错变化 | critic 每轮提出的怀疑数：被批评的答案对 / 错 | 2.96 / 2.96 | 2.81 / 2.86 |

- **M3 在两个模型上都接近零**：明确让模型审查自己的答案，它对正确答案和错误答案的质疑一样多。
- **M1、M2 因模型而异**，且 M2 在两批题上稳定（答对后保持：deepseek .92 与 .88，qwen .78 与 .75，MiniMax .84），模型间顺序不变。
- **由此的说法**：self-critique 不是模型的自知能力（M3 ≈ 0）；它是 M1、M2 不足时的替代品。M1、M2 已经较高的模型（deepseek），critique 没有可补的；M1、M2 低的模型（qwen），critique 带来的外部扰动才有净收益。
- 与"把握"的关系：M1、M2 和第 7 节的把握、第 5 节的停留长度，是同一件事（模型把多少概率压在某个答案上、压得对不对）的不同测法。
- **推测，不作结论**：这种分布上的差别可能与模型的训练有关（训练在强化正确答案的分布）；我们只观察到分布，观察不到训练。
- **限度**：M1 的差别（0.54 对 0.60）只有两个模型、一个题集；只有三个模型，不足以支撑"M1、M2 越高增益越小"的规律，只能说方向一致。

## 9. 统一模型：与 EIR/ECR 的关系

- **两状态链（accuracy）**：EIR = P(正确 → 错误)，ECR = P(错误 → 正确)；平稳分布 π_C = ECR/(EIR + ECR)。它解释的是准确率。
- **selection 需要多状态链**：对每个具体答案 a，票数 ≈ entry(a) × dwell(a)，dwell = 1/(1 − P(a→a))；mode = 票数最高者。两状态模型把所有错误答案并成一个状态，看不到"哪一个错误答案占住 mode"（第 4 节：多数情况下是首答）。
- **统一说法**：critique 同时抬高 EIR 与 ECR（让 loop 更爱动），支撑集变大（reach ↑），集中度变低（conversion ↓）。模型差异 = 基线分布的集中度，以及集中得对不对（第 8 节的 M1、M2）。
- **v2 注**：v1 的 7.4（"selected ≈ P(maxC > maxW)"）是 selected 的定义本身，数值接近是必然的，不构成对假设的检验。

**BBEH 读出之前写下的五条预测**（原文见 `REACH_SELECTION_DATA.md` 第 8 节；qwen；BBEH-hard 800 题、BBEH-easy 240 题）：

1. **P1**：critique loop 结束时"多数答案仍是首答"的比例随把握单调上升；把握 7–9 的题上不低于 .85，且首答对与首答错相差不超过 .10。
2. **P2**：BBEH-hard 上 critique 相对 reassuring 的 selected 增益，至少三分之二来自"把握 0–3 且首答错"的题。
3. **P3**：BBEH-easy 上 critique 相对 reassuring 的 selected 之差的绝对值不超过 12 题（240 题的 5%）。
4. **P4**：把握 7–9 的题上首答正确的比例，BBEH-easy 明显高于 BBEH-hard。
5. **P5**：用 qwen 在 HLE 新题上六类题（把握三层 × 首答对错）的每题平均效应，乘以 BBEH-hard 各类题的数量，得到预测净差；预测值落在实测净差的 95% 区间内视为外推成立。

P1 或 P2 不成立，即视为该解释在第二个题集上未得到支持。

**两个可做的操纵实验（未实施，视 BBEH 结果决定）**：

- **拿掉记忆**：critique loop 中 solver 看得到 critique、看不到自己上一轮的答案。预测：reach 更高，票更分散，selected 低于普通 critique loop，向独立采样靠拢；按第 8 节的说法，deepseek（M2 高）的损失应大于 qwen。
- **削弱粘性**：提高 loop 中 solver 的温度。预测：deepseek 各条件之间的差距变大，critique 的增益出现。这个操纵同时改变了别的东西，证明力弱于上一个。

**会推翻本假设的结果**：
- BBEH 上把握高的题，critique 仍大量改动首答（P1 不成立）；
- BBEH-hard 上的增益主要不在"把握低且首答错"的题上（P2 不成立）；
- BBEH-easy 上 critique 造成大幅损失（P3 不成立，说明"把握高就推不动"不成立）；
- 拿掉记忆后 selected 不降反升。
