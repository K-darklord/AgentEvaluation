# 第二次人工核对：新 800 题上 selected 背后的判分（2026-11-17，先于任何标注）

**目的。** 第一次核对（`audit/human_audit_20261111/`）里，qwen critique loop 的 4 条"判分器接受"中有 3 条被人工判为错误，样本太少，无法估计比例。S1、S2 比较的是 selected，而 selected 中约三分之一来自判分器接受而非精确匹配。本次核对估计三个 loop 各自的误接受率，看判分器是否偏向 critique loop。

**抽样**（`scripts/human_audit2_sample.py`，种子 20261117）。单位：某个 loop 在某题上的多数答案（或并列多数答案之一），且由判分器而非精确匹配判定，取其最后一次出现。模型 qwen，新 800 题。配额：判分器接受 84 条（critique 34，token-yoked 25，reassuring 25），判分器拒绝 16 条（6、5、5），共 100 条。

**流程**（与第一次相同）。隐去条件；两位标注者各自独立、顺序各自随机；选项为 correct / incorrect / unsure；不得使用任何大模型；两人不一致或有 unsure 的条目进入讨论表，由讨论得出最终判断；`key.json` 在两份表都交回之前不打开。

**报告**（写定）。
1. 每个 loop 的误接受率（人工判错 / 判分器接受）与误拒绝率，附精确二项区间；两位标注者的一致率。
2. critique 对 token-yoked、对 reassuring 的误接受率之差（Fisher 精确检验），仅作描述。
3. 敏感性：把各 loop "判分器接受"的 selected 部分按其估计的正确率折算后，S1、S2 的差是多少。
4. 无论结果如何写入论文附录；只计精确匹配的 S1、S2 已在论文中报告，不受本次核对影响。

## 修订（2026-11-19，早于任何标注；表格尚未发出）：与第一次核对的实际流程对齐

上文"流程（与第一次相同）"只写了第一次核对的**原始**设计。第一次核对在试标后改成了三条路径（`HUMAN_AUDIT_PLAN.md`"修订：三条路径"及之后各节），本次照搬那套最终流程，并把第一次事后才定下的规则提前写定：

1. **分流（先于标注，只看 `items.csv`，不看 `key.json`）**：每条归入 P1 直接比对 / P2 符号核验 / P3 讨论裁决，结果与原因写入 `audit/selection_audit_20261117/triage.json`，入库后不再改。第一次核对的教训一并采用：写法或题目规则下的等价（记号不同、集合写法、变量名不同等）和数值容差问题，分流时直接归 P3，不留在 P1。
2. **P1**：标注表只含 P1 条目（由 `scripts/human_audit_make_sheets.py` 的同一逻辑重新生成，原 100 条的表作废、不发出）。允许计算器和代数系统，禁用任何大模型，可选 unsure，`REF` 标记规则不变。任一人选 unsure 的条目转 P3。
3. **P2**：两式是否相同由代数系统（sympy 化简加随机数值代入）判定，逻辑式用真值表穷举；转写脚本入库（`scripts/human_audit2_cas_checks.py` → `cas_results.json`），由标注人确认转写；无法可靠转写的转 P3。
4. **P3**：讨论表由 `human_audit_make_discussion.py` 的同一逻辑生成。**先各自填写独立初判，再讨论**（第一次只记录到 35 条中的 13 条初判，这次初判是必填项）；可参考模型给出的理由，论文写作"model-assisted"。报告讨论前后两个一致率。
5. **数值规则（提前写定，沿用第一次讨论时定下的规则）**：答案须等于参考值按答案自身有效位数四舍五入后的值。
6. **标注人独立性**：若两位标注人确实分开、互不看对方结果，报告一致率与 κ；若做不到（第一次即如此），如实写作"一位标注人加一位复核人"，不报告 κ。
7. **最终读出**：`scripts/human_audit2_final.py`（照 `human_audit_final.py`），报告按路径的一致数、各 loop 的误接受率与误拒绝率（精确二项区间）、critique 对其他 loop 的差（Fisher，描述性），以及按估计正确率折算后的 S1、S2 敏感性。
8. **范围说明**：本样本只覆盖三个 loop，不含等 token 采样被选中的答案；对 E2 的支撑以"只计精确匹配"的稳健性结果为主。
