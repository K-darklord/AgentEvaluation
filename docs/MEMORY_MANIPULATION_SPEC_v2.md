## 1. 目的（三句）

1. BBEH 读出后的解释是"loop 的记忆买集中"（`MECHANISM_SYNTHESIS_20261118.md`），但这只是事后解释，没有直接证据。
2. 本实验直接操纵记忆：**反馈内容不变，只是 solver 看不到自己上一轮的答案与推理**。
3. 只有"不含内容的反馈"（通用怀疑）这一条线能做确认性检验；critique 线的批评会指代一个 solver 看不到的对象（§7.1），只能作描述。

## 2. 设计：四个条件，只有一条确认性线

| 条件 | 记忆（可见性） | 许可（"认为对就保留"） | 反馈 | 状态 |
|---|---|---|---|---|
| **A2PY**（已有） | 有 | 有 | 五句固定通用怀疑，token-yoked | 基线 |
| **G-NM**（新，800） | **无** | **无** | 同上，token-yoked | **唯一确认性条件** |
| **G-KI**（新，400） | 有 | **无** | 同上，token-yoked | 拆分用 |
| **C2-NM**（新，400） | **无** | **无** | critique（critic 不变，仍读上一轮答案） | 仅描述 |

- **A2PY / G-NM / G-KI 都没有 critic 调用**；反馈是模板文本，不含任何与答案有关的内容。
- **C2-NM 的 critic 与 C2 完全相同**（读题目 + 上一轮答案 + 推理，写怀疑）。只有 solver 的输入变了。
- 停止规则：G-NM、G-KI 与 A2PY 相同（不因重复而停；跑到累计 solver token ≥ 该题的预算；上限 100 轮）。**预算文件与 A2PY 相同：`experiments/hle400/t3/yoke_budget_bbeh_hard.json`，即 critique loop（C2）在该题上的 solver 加 critic token。**C2-NM 与 C2 相同（连续三次相同答案即停，最多 10 轮）。

### 2.1 solver 提示词的三处改动

只改 `src/run_feedback_loop.py` 的 `_feedback_message` 生成部分：

1. 删去 `Your previous answer was: …` 一段（及随附的推理摘录）；
2. 删去 `If you believe your previous answer was already correct, keep it as is.` 一句；
3. 把要求"说明为何改动或保留上一轮答案"的输出格式，改为只要求给出答案与理由。

4. （仅无记忆条件）把指向"你上面的答案"的措辞改为"此前一次作答（未显示）"。

其余文字、参数、token 上限、温度不变。

**G-KI 只做第 2、3 项**（保留上一轮答案的呈现）。
**G-NM 做第 1、2、3、4 项**（无呈现、无许可）。
**C2-NM 做第 1、2、3、4 项**，且 critic 侧完全不变。

改动处须在运行前回报并得到确认。

## 4. 判分

- BBEH 用官方规则函数（与生成 `bbeh_sidecar.json` 的是同一份脚本、同样的键规则），写入 `experiments/hle400/t3/bbeh_sidecar_nm.json`，arm 名为 `GNM`、`GKI`、`C2NM`。
- 格式与 `bbeh_sidecar.json` 相同：`{"arms": {arm: {task_id: [{"c": bool, "k": key|None}, ...]}}}`。
- BBEH 的判分是规则函数，不调用任何接口。每条轨迹的每一轮都必须有判定；任何一轮没有判定，停下回报，不生成判分文件（读出脚本要求判分轮数与轨迹轮数逐题相等）。

## 5. 读出（`scripts/memory_manipulation_readout.py`；运行前提交并记哈希）

### 5.1 操纵检查（先于确认性检验，且决定它是否可判）

去掉记忆必须确实改变 solver 的行为。检查量：**第 1 轮答案与首答相同的题目比例**（四个条件首答相同；第 1 轮不受停止规则影响；按判分文件的键比较）。

- 对象：**G-NM 对 A2PY**（800 题）。
- 判据：G-NM 的比例低于 A2PY，且精确 McNemar **p < .05 且绝对差 ≥ 5 个百分点**（两者同时满足）。
- 若操纵检查不通过：NM-2 标为**"操纵未生效，不作判定"**，不得解读为"记忆无用"；并如实报告"在提示词中呈现上一轮答案不是 loop 重复答案的原因"。

### 5.2 确认性检验（唯一一条）

**NM-2（BBEH-hard，800 题）**

- 量：`selected(A2PY) − selected(G-NM) > 0`。
- selected 定义沿用主实验：出现次数最多的候选正确（随机平票取期望）。
- 检验：题目级符号翻转置换检验（10,000 次），双侧，方向须为正；bootstrap 95% 区间。α = .05，无多重校正（只有一条确认性检验）。
- **前置条件（不满足则不作判定）**：G-NM 的 solver token **总量**在预算总量的 **95%–120%** 之间（与 A2PY、token-yoked 对照的判据相同；每题会因最后一轮越界而略有超出，不按每题判定）；触顶（100 轮）题数 **≤ 40**。

### 5.3 描述性（不设判据）

1. **可见性 vs 许可的拆分**（400 题子集，仅通用怀疑线）：
   - 许可 = `selected(A2PY) − selected(G-KI)`；
   - 可见性 = `selected(G-KI) − selected(G-NM)`；
   - 各给 95% bootstrap 区间。所有条件取同一 400 题。
2. **C2-NM 线**：`selected(C2) − selected(C2-NM)`（同一 400 题）、reached、候选数、token、轮数。只作描述。
3. **泄露与指代**：C2-NM 上报告 §7.1 的两类比例。
4. 无记忆条件的 reached、每题候选数、答对/答错后的重复概率、到达后转化、对九次采样的 selected 之差（附区间）。

### 5.4 措辞规则（事先写定）

- NM-2 成立、且可见性之差的区间下限 > 0 → 论文可写"**呈现上一轮答案提高 selection**"。
- NM-2 成立、但可见性之差不成立 → 只能写"**上一轮答案及其保留许可，作为一个整体，提高 selection**"，并同时报告两部分估计。
- NM-2 不成立 → 见 §6。

## 6. 判定与论文处理

| 结果 | 论文处理 |
|---|---|
| NM-2 成立（操纵检查通过、token 对齐达标） | "loop 的记忆（整体）提高 selection"写为有直接操纵证据的结论，可进入摘要；是否单写"可见性"按 §5.4。critique 线的说法只能依据描述性结果 |
| NM-2 不成立（操纵检查通过） | "记忆买集中"从论文撤下；loop 优于采样的原因写为未知 |
| NM-2 不作判定（操纵未生效或 token 未对齐） | 如实报告；不下结论，不写成"记忆无用" |

**符号相反的读法（事先写定）**：记忆既集中正确答案，也锁定错误答案。若 NM-2 的差显著为负，不视为实验失败，如实写为"记忆的净效应在该题集上为负"。

## 7. 已知限制（写进论文，不设阈值）

**7.1 指代不明（决定 C2-NM 只能是描述性）**
C2-NM 的 critic 仍读得到上一轮答案，solver 看不到。已有 C2 运行上量过：含 `your answer / you said / your previous / your computation` 的 critique 仅 **0.4%**，但指向"此前那次作答做了什么"（`assumed / treated / chosen / asserted` 等）的约占 **四分之三**（BBEH-hard 78%，HLE 76%）。这个偏差与"记忆有用"同向，无法用字符串阈值拦住，因此 **C2-NM 不进入确认性判定**。

**7.2 泄露**
critique 文本可能显式提到上一轮答案（已有 C2 上 BBEH-hard 8%，HLE 28%）。它使差偏小（保守），与 7.1 方向相反。

**7.3 温度**
loop 用 T=0，独立采样用 0.7。本实验两条件温度相同，检验的是"在 loop 的设置下呈现上一轮答案是否提高 selection"；无记忆条件与独立采样的比较仍受温度影响，只作描述。

**7.4 单一模型、单一题集**
只有 qwen、只有 BBEH-hard。结论不外推到其它模型或开放式题集。
