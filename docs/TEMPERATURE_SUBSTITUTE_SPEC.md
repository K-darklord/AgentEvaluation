## 1. 问题

现有综合（`MECHANISM_SYNTHESIS_20261118.md`）把 loop 的优势拆成两项：**记忆买转化、token 买 reach**。critic 的作用是"在不丢记忆的前提下强行多跑几轮"。

于是一个直接的问题：

> **如果把 solver 换成 T=0.7、保留 loop（反馈不变、有记忆），能不能得到和 critic 一样的效果？**

如果答案是"能"，那么 critic 不是必需品——论文的主张必须从"critique 提高 selection"改成"**记忆 + 温度提高 selection**"。

---

## 2. 现有数据说明了什么（HLE qwen 800 / BBEH-hard）

| 方法 | reach | 转化 | selected |
|---|---|---|---|
| critique loop（T=0） | 348（HLE）/ 591（BBEH） | .59 / .66 | 205.3 / 390.5 |
| 九次采样（T=0.7，无记忆） | 329 / 547 | .54 / .63 | 178.1 / 344.4 |
| token-yoked 通用怀疑（T=0，有记忆） | — / 576 | — / .65 | 181.5 / 371.9 |

- **reach**：T=0.7 采样已经接近 critique（HLE −19，BBEH −44），token-yoked 通用怀疑甚至追平（BBEH 576 对 591）。→ **reach 由 token 决定，不由 critic 决定。**
- **selection**：T=0.7 采样差在转化（.54 对 .59；.63 对 .66），因为它**没有记忆**，票被摊开。
- **缺的一格**：**T=0.7 + 有记忆的 loop**。这一格既没有温度造成的低转化，也没有 critic。它正是"温度替代 critic"的候选。

## 3. 设计：一臂，token 对齐

| 条件 | 温度 | 反馈 | 记忆 | 状态 |
|---|---|---|---|---|
| A2P-T07（新） | **0.7** | 通用怀疑（五句固定，无内容） | 有（上一轮答案照常呈现） | 跑 800 |
| C2（已有） | 0 | critique | 有 | 基线 |
| A2PY（已有） | 0 | 通用怀疑 | 有 | 等 token 基线 |
| A3（已有） | 0.7 | 无（独立采样） | 无 | 无记忆对照 |

- **A2P-T07 = A2P 的反馈 + T=0.7 + 每轮呈现上一轮答案 + 不因重复而停、跑到 C2 的 token 预算（与 A2PY 同一预算文件）**。
- 只改温度；提示词、停止规则、token 上限不动。
- 题集：**BBEH-hard 800**（规则判分，最干净；且是 loop 对采样优势最大的一格）。若预算允许再加 HLE 800。

**为什么不用 critique + T=0.7**：那测的是"温度是否在 critic 之上再加东西"，不是"温度能否替代 critic"。要做前者，另开一臂（C2-T07），本规格不含。

## 8. 与记忆操纵的关系

两者测的是同一句话的两半：

```
selected = f(reach, 转化)
reach    ← token（温度是一部分）
转化     ← 记忆
critic   ← 同时提供 token 与记忆，但不提供对错信息（M3）
```

- **温度实验（本文件）**：固定记忆、变温度 → 分离 reach 的贡献；
- **记忆实验（v3.1）**：固定温度、去记忆 → 分离转化的贡献。

两个都做，才能把"loop > 采样"完整分解。若只做一个，**先做本文件**：它更便宜、更直接，而且它的第三条预测（A2P-T07 > A3）如果成立，等于顺带确认了记忆的作用。

---

## 9. 局限

- 单模型（qwen）、单题集，除非加 HLE。
- T=0.7 改变的不只是"多样性"：答案长度、截断率、token 效率都会变；token 对齐只对齐总量，不对齐分布。
- 非劣性边际（−10）是事先写死的判断标准，不是统计检验的发现；论文里必须写明这是**预先声明的实用判据**。
