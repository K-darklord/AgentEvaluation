## 1. 要检验的假设

论文 v14 在 Discussion 里提出一个假设：critic 对 reach 的增益是通用的，对 selected 的增益取决于模型。现有 400 题上：

- critique loop 比 reassuring loop 多选对的题数：qwen +23.3 [8.8, 39.2]，MiniMax +5.2 [−6.9, 18.0]。
- 两者之差 +18.0 [−0.2, 36.8]，p = .07，**尚未确立**。
- 这两个数字都不是事先登记的检验（MiniMax 的 +5.2 是已登记且未通过的确认性检验）。

本实验在全新的题上，用事先写定的检验回答两个问题：
- **P1**：在 qwen 上，critique loop 是否比 reassuring loop 选对更多的题。
- **P2**：这一增益在 qwen 上是否大于在 MiniMax 上。

P1 成立，论文得到一个确认的正结果（"至少在一个模型上 critic 提高了 selection"）。P2 也成立，"取决于模型"从假设变为（这两个模型上的）结果。

## 2. 设计

- 模型：`qwen3.8-flash-payg`、`minimax-m2.5`。选它们的理由（先于运行写定）：现有数据里 selected 增益最大和最小的两个模型。deepseek 不参加。
- 题目：从 HLE 纯文本题中、去掉已用过的 400 题后，按与原题集相同的规则（按学科比例分层、固定种子）抽两批，每批 400 题：第一阶段 `hle_confirm_s1.jsonl`，第二阶段 `hle_confirm_s2.jsonl`。抽样脚本 `scripts/build_hle_confirm_sets.py`（只读题库，不读任何实验输出）；抽样由执行 agent 在下达后运行一次，抽出后不得更换、不得剔除任何题。
- 条件：A、A2、C2、A2P，每个模型各跑。设置、提示词、停止规则与现有运行完全相同（温度 0，thinking 预算 16,384，输出上限 8,192，最多 10 个反馈轮，连续三次相同即停）。
  - A2P 不参与主检验，用于复核机制（第 4.3 节）。作者可在下达前决定去掉它以节省约 45M token / 阶段。
- 两阶段：先跑第一阶段的 400 题并读出一次；按第 4.2 节的规则决定停止或继续第二阶段。
- 运行规则与判分：与 `REPLICATION_SPEC.md`、`THIRD_MODEL_SPEC.md` 相同。含接口失败轮的轨迹整题重跑；报错文本不算答案；判分为冻结口径（截断为错 → 精确匹配 → grader K1 → 已有裁决规则），不新开争议复判；同时报告"只计精确匹配"的结果作为敏感性分析。阶段内不查看任何对错。

## 4. 读出（判据在此写定）

读出脚本 `scripts/model_dependence_readout.py` 在数据到齐后由分析方编写，只实现本节。量的定义与论文相同：selected = 平局随机下的期望得分；检验为题目级符号翻转置换检验（10,000 次），区间为题目级 bootstrap 95%。

### 4.1 两个主检验
- **P1**：qwen 上 selected(C2) − selected(A2) > 0。
- **P2**：[selected(C2) − selected(A2)]（qwen）− [同一差值]（MiniMax）> 0，逐题配对。
- 两个检验都按双侧 p 值判定，方向须与假设一致。

### 4.2 两阶段与显著性水平
总的第一类错误率控制在 .05：两个检验各分得 .025（Bonferroni），每个检验再在两次读出之间分配（并集界，对任何相关结构都成立）：

| 读出 | 所用题目 | 每个检验的 p 值阈值 |
|---|---|---|
| 第一阶段后 | 新题 400 | p < .002 |
| 第二阶段后 | 新题 800（两批合并） | p < .023 |

第一阶段读出后的规则（事先写定，只读一次）：
- 某个检验 p < .002：该检验**成立**，不再为它跑第二阶段。
- P1 的估计值 ≤ 0：**停止整个实验**，P1、P2 都记为未确认。
- P2 的估计值 ≤ 0 而 P1 的估计值 > 0：P2 记为未确认；第二阶段只为 P1 继续（只跑 qwen 的 A、A2、C2）。
- 其余情况：跑第二阶段，在 800 题上做最终检验。
- 两个检验都在第一阶段成立：不跑第二阶段。

现有 400 题的数据不进入任何主检验；合并三批（1,200 题）的估计只作为探索性结果报告。

### 4.3 次要检验与描述（各自 α = .05，不影响主检验的判定）
- reach：C2 对 A2、C2 对 A2P，每个模型（精确 McNemar）。预期复现。
- MiniMax 上 selected(C2) − selected(A2) 的估计与区间。
- 机制复核（需要 A2P）："第一个候选错、出现第二个候选时，第二个候选正确的比例"，C2 对 A2P，每个模型；以及这一差别在两个模型之间的差（bootstrap 区间）。假设预期：qwen 上 C2 高于 A2P，MiniMax 上两者接近。
- conversion、每题候选数、改答比例、重复概率、token。
- "只计精确匹配"下的 P1、P2。

### 4.4 功效（按现有标准误估计）

| | 真实效应 | 只做第一阶段（400 题，阈值 .002） | 做满两阶段（800 题，阈值 .023） |
|---|---|---|---|
| P1：qwen 增益 | 23 题 / 400 | 约 44% | 约 97% |
| | 15 题 / 400 | 约 12% | 约 67% |
| P2：模型间差 | 18 题 / 400 | 约 12% | 约 66% |
| | 12 题 / 400 | 约 3% | 约 32% |

第一阶段主要起"效应方向不对就止损"的作用，结论通常要到 800 题才能下。P2 即使做满两阶段，在真实差距为 12 题时也只有约三分之一的把握；**P2 不显著不等于模型间没有差别**，届时报告估计值与区间。

### 4.5 判定与论文处理

| 结果 | 结论 | 论文处理 |
|---|---|---|
| P1 成立，P2 成立 | critic 在 qwen 上提高了 selected，且增益大于 MiniMax | 摘要第二条改为：对安慰剂 loop 的 selected 增益在 qwen 上得到确认，在 MiniMax 上未确立，两者之差得到确认；"取决于模型"写为这两个模型上的结果，机制仍为假设 |
| P1 成立，P2 不成立 | critic 在 qwen 上提高了 selected；是否取决于模型仍未确立 | 摘要第二条改为：在一个模型上得到确认；"取决于模型"保留为假设，并报告 P2 的估计与区间 |
| P1 不成立 | qwen 上的增益在新题上未得到确认 | 摘要第二条保持"未确立"，并写明新题上的复现未通过；Discussion 的假设一段相应削弱或删去 |
| P1 不成立，P2 成立 | 模型间有差别，但 qwen 自身的增益未确认 | 两者都如实报告，不下进一步结论 |

无论结果如何，全部写入论文；提前停止时写明停止规则与停止时的估计值。结论限于这两个模型，不外推为"模型能力"的结论。
